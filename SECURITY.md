# Модель угроз

Публичное демо, которое показывает текст, пришедший из интернета, и обращается к языковой
модели. Отсюда три поверхности.

## Недоверенный ввод в разметке

Заголовки и тексты новостей приходят с чужих сайтов. Весь HTML с подсветкой фактов
собирается **одной функцией** `app/highlight.py:render_spans`: она режет текст по смещениям,
экранирует каждый фрагмент через `html.escape` и только сама добавляет теги `<mark>`.
В шаблонах нет ни одного `|safe`.

Тест `test_render_spans_escapes_everything` подаёт строку
`<img src=x onerror=alert(1)> … </mark><script>alert(2)</script>` и проверяет, что в выводе
не осталось ни одного живого тега, кроме наших.

## Недоверенный ввод в промпте

Текст статьи может содержать инструкции для модели. Он оборачивается в блок со случайной
меткой на каждый вызов, а в системной части сказано, что всё внутри блока — данные.
Метку нельзя подделать заранее в тексте статьи, потому что она генерируется в момент запроса.

## Секреты

- Ключи и токены только в переменных окружения, файл `/etc/mood-news.env` с правами 600.
- В репозитории лежит `.env.example` с пустыми значениями.
- **На публичном сервере токена доступа к модели нет вообще**: конвейер генерации живёт на
  машине автора, сервер только читает готовую базу.
- Живая перегенерация по кнопке выключена по умолчанию (`ALLOW_LIVE_REGENERATE=0`).

## Изоляция сервиса

Сервис работает под отдельным системным пользователем: `NoNewPrivileges`, `ProtectSystem=strict`,
`ProtectHome=yes`, `PrivateTmp`, пустой `CapabilityBoundingSet`, `SystemCallFilter=@system-service`,
запись разрешена только в два каталога проекта, лимит памяти 400 МБ.
nginx ограничивает частоту запросов и размер тела.

## Внешние ресурсы

Ни одного. Шрифты локальные, Swagger с внешнего CDN отключён. Проверяется тестом
`test_tz_no_external_cdn_anywhere`, который грепает шаблоны и стили на внешние адреса.

## Данные посетителей

Не собираются: ни счётчиков, ни куки, ни аналитики. Свободный ввод нигде не сохраняется.
