# Mood News Grid

Настоящие новости из открытых лент, которые читаются в четырёх эмоциональных режимах.
Факты при этом не меняются — и это не обещание в документации, а проверка, которая
блокирует публикацию.

**Демо:** https://bogemadumb.ru/mood/
**Короткий маршрут для проверяющего:** https://bogemadumb.ru/mood/review — 90 секунд, четыре
якоря и честный список того, что здесь слабо.

Запуск одной командой без ключей и без интернета:

```bash
uv venv --python 3.12 && uv pip install -e ".[dev]" && make dev
```

## Чем эта работа отличается

**Проверка фактов детерминированная, а не «попросили модель не врать».** Из оригинала
извлекаются числа, даты, деньги, проценты, имена, организации, топонимы и цитаты со
смещениями в тексте. Затем каждый ищется в пересказе по ступеням: точное вхождение →
числовое сравнение с нормализацией множителей → числительные прописью → леммы → словарь
синонимов → нечёткое сравнение. Всё локально, бесплатно, 12–40 мс на пару текстов.
Модель к проверке не привлекается вообще — иначе пришлось бы верить уже двум моделям.

**Есть вторая половина проверки: что ДОБАВИЛОСЬ.** Тот же экстрактор гоняется по
пересказу, и всё, чего не было в оригинале, попадает в галлюцинации. Стоит ноль,
ловит половину искажений.

**У метрики есть страховка от обмана.** С гейтом только по фактам модель быстро находит
выигрышную стратегию: вернуть оригинал дословно и получить 100% сохранности. Поэтому
второй гейт — по стилистической дистанции: слишком похожий на оригинал текст получает
статус `COPY` и уходит на перегенерацию.

**Запрет ручного написания доказан на уровне данных.** Строка пересказа физически не
сохранится в базе без ссылки на конкретный вызов модели: это `CHECK` в схеме. Тест
дополнительно сверяет, что опубликованный текст посимвольно содержится в сыром ответе
модели и что промпт не подкручивался под отдельные новости.

**Продукт отказывается шутить над трагедией** и объясняет, по какому правилу отказался.

**Настроение меняет типографику, а не цвет кнопки.** Радость набрана плотнее и жирнее,
печаль — тоньше и с большим интерлиньяжем, ирония курсивом. Это идея продукта,
показанная средствами набора.

## Как запустить

### Без ключей и без интернета

```bash
uv venv --python 3.12
uv pip install -e ".[dev]"
make dev          # или: .venv/bin/uvicorn app.main:app --reload --port 8040
```

Откроется на `http://127.0.0.1:8040`. Если в `data/news.db` нет базы, лента будет пустой —
это честное состояние, а не ошибка.

### Собрать свои новости

```bash
make cycle        # сбор из лент, отбор витрины, разметка стоп-краном
```

Сеть нужна, ключи нет. После этого в ленте появятся настоящие новости без пересказов.

### Сгенерировать пересказы

Нужен доступ к языковой модели. Провайдер выбирается переменной `LLM_PROVIDER`:

```bash
# вариант 1: любой OpenAI-совместимый endpoint (z.ai, LM Studio, Ollama)
export LLM_PROVIDER=openai
export LLM_BASE_URL=https://api.z.ai/api/paas/v4
export LLM_API_KEY=ваш-ключ
export CLAUDE_MODEL=glm-4.6        # имя модели для выбранного провайдера

# вариант 2: подписка Claude через её командную строку
export LLM_PROVIDER=claude_cli

# вариант 3: заглушка, чтобы посмотреть конвейер без модели
export LLM_PROVIDER=echo

make rewrite
```

Смена провайдера не требует правок нигде, кроме переменной окружения: интерфейс один
(`pipeline/llm.py`), за ним три реализации.

**Оговорка про Python.** Проверено на 3.12. На 3.13 и 3.14 не проверялось.
В зависимостях жёстко закреплён `setuptools<81`: natasha тянет pymorphy2, который
импортирует `pkg_resources`, а в setuptools 81+ этого модуля больше нет, и `import natasha`
падает. Ещё один пин — `text2num<3`: в третьей версии, переписанной на Rust, русский язык
пропал.

## Откуда берутся новости

Шесть открытых RSS-лент. Выбор не случайный: нужны издания, отдающие осмысленный объём
текста — переписывать под настроение заголовок из шестидесяти знаков бессмысленно.

| Издание | Чем извлекается текст | Почему выбрано |
|---|---|---|
| РБК | полный текст прямо в ленте | единственный крупный общественно-политический источник с полным текстом в фиде |
| Лента.ру | CSS-селектор страницы | быстрая лента; без куки `unity_pause_sso=1` сайт отдаёт JS-заглушку на 1757 байт вместо статьи |
| Коммерсантъ | CSS-селектор страницы | деловые новости, плотные по фактам |
| N+1 | лента + trafilatura | наука: поток материалов без человеческих трагедий |
| Naked Science | trafilatura | научпоп, второй безопасный источник |
| 3DNews | CSS-селектор страницы | технологии, много чисел и названий компаний |

**Каскад извлечения нужен, и вот замер.** Три свежие статьи каждого издания,
три способа, знаков полезного текста:

| Издание | trafilatura | свой селектор | JSON-LD |
|---|---|---|---|
| Лента.ру | 637–1205 | 637–1205 | нет |
| Naked Science | **6689–9682** | 2442–6522 | нет |
| 3DNews | 775–3098 | **2902–4818** | нет |

Универсального победителя нет: на одном издании trafilatura выигрывает вчетверо,
на другом вчетверо проигрывает. Поэтому у каждого источника в `pipeline/sources.yml`
своё поле `prefer`, и это решение выведено из цифр.

**Гейт качества** отсекает мусор до попадания в базу: длина от 400 знаков, отсутствие
маркеров юридического подвала, доля длинных предложений не ниже 0,6 и пересечение лемм
заголовка с текстом не ниже 0,3 — по леммам, а не словоформам, иначе заголовки-каламбуры
выбрасываются вместе с мусором.

**Вежливость сбора:** свой User-Agent с контактом, `ETag`/`If-Modified-Since`, пауза между
запросами, соблюдение `robots.txt` (выкачаны и закоммичены в `docs/robots/`, полных
запретов ни у одного источника нет).

**Что не берём и почему:** ТАСС и РИА — в их лентах текста нет вообще; издания со статусом
нежелательной организации — осознанно, это создаёт персональные риски автору публичного
репозитория.

## Как хранятся данные

Один файл SQLite в режиме WAL, 13 таблиц. Не PostgreSQL: на объёме тридцати новостей
он был бы лишним сервисом в инструкции запуска и лишним абзацем на защите.

| Таблица | Зачем |
|---|---|
| `sources` | источник как конфигурация, а не хардкод: адрес фида, способ извлечения, ETag |
| `articles` | новость, единое окно исходного текста, отпечаток, снимок страницы, чувствительность |
| `facts` | извлечённые факты со смещениями — основа парной подсветки |
| `moods` | тона: промпт, температура и **типографика**; добавить режим — это строка, а не вёрстка |
| `rewrites` | каждая попытка пересказа со всеми метриками; `CHECK` не даёт сохранить текст без вызова модели |
| `fact_checks` | результат сверки по каждому факту |
| `hallucinations` | то, чего в оригинале не было |
| `semantic_checks` | отрицания, модальность, усилители |
| `llm_calls` | каждый вызов модели: кэш, кассета для тестов и доказательство неручного написания |
| `pipeline_runs`, `source_health`, `provider_health`, `incidents` | наблюдаемость |

Данные видно из браузера, а не только после клонирования: [/api/articles](https://bogemadumb.ru/mood/api/articles),
[/api/sources](https://bogemadumb.ru/mood/api/sources), [/api/stats](https://bogemadumb.ru/mood/api/stats).

**Единое окно исходного текста.** В витрину попадают только заметки 800–4000 знаков, и
оригинал показывается целиком. Это закрывает пункт 5 ТЗ без обрезки: если оригинал
подрезать, читатель увидит справа факты, которых нет слева, и это будет выглядеть как
провал проверки. У текста хранится sha256, и он же дублируется в строке пересказа —
видно, что модель и человек смотрели на одно и то же.

## Как переписывается тон

Промпты лежат в таблице `moods` и показываются в интерфейсе кнопкой «каким промптом это
сделано» — их не нужно искать в коде.

| Режим | Температура | Порог непохожести |
|---|---|---|
| нейтрально | 0,4 | 0,06 |
| радостно | 0,85 | 0,15 |
| грустно | 0,8 | 0,15 |
| иронично | 0,9 | 0,15 |

Порог у нейтрального ниже намеренно: новость и так написана нейтральным языком,
требовать от такого пересказа сильного расхождения значит требовать перефразирования
ради перефразирования, а это прямой путь к искажению.

**Изоляция недоверенного ввода.** Текст новости приходит из интернета, то есть это
враждебный ввод. Он оборачивается в блок со случайной меткой:

```
<<<ARTICLE 8f2a1c9d>>>
…текст статьи…
<<<END 8f2a1c9d>>>
```

В системной части сказано, что всё внутри блока — данные, а не инструкции. Метка
случайная на каждый вызов, поэтому её нельзя подделать заранее в тексте статьи.

**Числительные прописью разрешены.** Запрет «только цифрами» решил бы задачу проверки,
но искалечил продукт: «бережные» и ироничные интонации естественно тянут к «почти три
с половиной миллиарда». Вместо запрета — обратная конвертация в проверке.

## Как контролируются факты

Самый длинный раздел, потому что это ядро работы.

### Слои проверки

**Слой 0, детерминированный.** Числа, деньги, проценты: нормализация разделителей и
множителей (тыс/млн/млрд/трлн), сравнение как чисел, а не строк. Даты — сравнение
кортежей после разрешения относительных («вчера» относительно даты публикации).
Матчер перебирает всех кандидатов и берёт лучший статус: в тексте одно и то же число
может встретиться дважды.

**Слой 1, сущности.** Совпадение последовательности лемм — так «Собянин» и «Собянина»
остаются одним фактом. Дальше словарь синонимов (США / Соединённые Штаты, ЦБ /
Центробанк / Банк России), для людей допускается сокращение до фамилии, в конце
нечёткое сравнение.

**Слой 2, цитаты.** Точное вхождение после нормализации кавычек и пробелов. Отдельно
сверяется говорящий.

**Слой 3, семантика.** Отрицания, потеря осторожных формулировок («может» → утверждение),
добавленные усилители («впервые», «рекордный»).

**Обратная проверка.** Тот же экстрактор по пересказу: всё, чего не было в оригинале,
это галлюцинация.

### Правило публикации

Одна цифра врёт: подмена Reuters на ТАСС даёт сохранность 95%. Поэтому гейт не пороговый,
а типовой:

```
ОПУБЛИКОВАТЬ ⟺
    ноль жёстких нарушений фактов
  И ноль галлюцинаций
  И ноль переворотов смысла (отрицания, модальность, усилители)
  И длина в пределах 0,6–1,6 от оригинала
  И доля кириллицы ≥ 0,85
  И непохожесть ≥ порога своего режима
```

Не прошло — ремонтный промпт с адресным списком нарушений («пропало: 3,5 млрд рублей;
изменено: 12% → 15%; выдумано: Новосибирск»), до трёх попыток с падающей температурой.
Все попытки сохраняются и показываются в журнале на странице сравнения.

### Что считается изменением факта, а что нет

| Ситуация | Вердикт |
|---|---|
| «Собянин» → «Собянина» (падеж) | норма |
| «США» → «Соединённые Штаты» | норма |
| «по словам Санчеса» → «Санчес заявил» | норма |
| «сообщил в своём канале в „Максе“» → упоминание площадки выброшено | замечание, не блокировка |
| «250 млн» → «250 млрд» | блокировка |
| «Reuters» → «ТАСС» | блокировка |
| «не смогли договориться» → «смогли договориться» | блокировка |
| цитата сокращена многоточием | блокировка |
| выдумано число, которого не было | блокировка |

### Пример, где проверка не прошла

Ироничный пересказ спортивной новости, попытка 1:

```
FAIL  сохранность фактов 100%  непохожесть 0.25
      добавлено усиление, которого не было: «все»
```

Факты целы, но модель усилила утверждение. Ремонтный промпт получил именно эту строку,
и вторая попытка прошла. Живые примеры брака лежат на странице
[карантина](https://bogemadumb.ru/mood/karantin).

## Чего эта проверка НЕ гарантирует

Читать обязательно, если вы собираетесь ей доверять.

**Она сверяет текст с источником, а не с реальностью.** Если новость врёт, пересказ
повторит ложь и получит зелёный штамп.

**Полнота извлечения не измерена численно.** Стенд с искусственными искажениями,
подсчётом полноты и доли ложных срабатываний на честных перезаписях запланирован,
но не сделан. Сейчас есть 17 ручных кейсов, на которых детектор классифицирует всё
верно, — этого мало, чтобы называть цифру.

**Известные дыры.** Относительная дата при непарсящейся дате публикации. Перестановка
ролей внутри предложения («А обвинил Б» → «Б обвинил А») — синтаксическая проверка троек
подлежащее-сказуемое-дополнение спроектирована, но не включена. Ирония, читаемая как
утверждение. Факт, который NER не извлёк вовсе, — его пропажу заметить нечем.

## Как доказано, что тексты не написаны руками

Это центральный запрет ТЗ, и обычно его «доказывают» рассказом.

1. `rewrites.llm_call_id` с ограничением `CHECK`: текст с `generator='llm'` не сохранится
   без ссылки на вызов модели.
2. `tests/test_no_handwriting.py`: у каждого опубликованного текста вызов существует,
   завершился успешно, и текст **посимвольно содержится в сыром ответе модели**.
   Подставить сюда написанное руками невозможно, не подделав заодно ответ модели.
3. Промпт не подкручивался под отдельные новости: число различных отпечатков промпта
   на пару «режим + версия» равно единице.
4. Кнопка **«перегенерировать»** на экране сравнения: проверяющий получает текст,
   которого минуту назад не существовало, с новым номером вызова.
5. Строка-инвариант на [странице статистики](https://bogemadumb.ru/mood/stats):
   «опубликованных текстов без записи вызова модели: 0».

## Стоп-кран

На новостях о гибели людей режимы «радостно», «грустно» и «иронично» отключены.
Вместо пересказа страница объясняет, по какому правилу сработал запрет, и предлагает
нейтральный вариант.

**Появился не из осторожности.** На живом прогоне модель трижды подряд отказалась
пересказывать бодро новость о гибели 19-летнего велогонщика и написала открытым текстом,
что конвейеру нужен классификатор, отсекающий такие материалы до отправки в модель.
Ответы при этом не разбирались как JSON и попадали в статистику как техническая ошибка.
Классификатор появился.

**Как устроен.** Не список запретных слов: тогда «убийственный ценник», «гибель урожая» и
«мёртвый сезон» ушли бы в блок. Проверяется триггерная лемма плюс синтаксически связанное
существительное — одушевлённое или из списка слов о людях. На контрольном наборе из восьми
случаев, включая три метафоры-ловушки, восемь верных решений.

## Что использовалось из AI

**В рантайме модель делает ровно одно: переписывает текст под интонацию.** Всё остальное —
детерминированный код: извлечение фактов регулярками и морфологией, сверка, правило
публикации, ремонтный цикл, классификатор чувствительности. Решение не проверять модель
второй моделью осознанное: пришлось бы верить уже двум, платить за каждый показ и объяснять,
почему судья не ошибается.

**При разработке** использовался Claude Code. Методика и живые выдержки — в
[`docs/AI-WORKFLOW.md`](docs/AI-WORKFLOW.md), включая случаи, где предложение модели
оказалось неверным и как это выяснилось.

**Про z.ai, который вы предложили.** Аккаунт зарегистрирован, ключ выпущен и работает:
`GET /v4/models` отдаёт девять моделей, включая glm-5.2. Но любой вызов генерации
возвращает `1113 Insufficient balance` — бесплатного тарифа у международного z.ai сейчас
нет, а `glm-4-flash`, который раньше был бесплатным, из каталога исчез (`1211 Unknown Model`).
Поэтому витрина собрана через подписку Claude, а провайдер сделан сменным: подставить ключ
z.ai и повторить прогон — это одна переменная окружения.

## Что я узнал, пока это делал

Пять дефектов, найденных на живых данных. Все пять — **ложные срабатывания проверки,
ни одного пропущенного искажения**. Строгая проверка гораздо охотнее запрещает нормальный
текст, чем пропускает подлог.

1. **Отрицания.** Считались частицы «не» в обоих текстах. Ирония живёт на отрицаниях
   («решила не отвлекаться», «это уже не сенсация») — корректный текст с сохранностью 100%
   браковался трижды подряд. Теперь сравнивается привязка отрицания к сказуемому:
   пропало «не» у того же глагола — подлог, появилось у нового — стилистика.

2. **Падежи говорящего.** «по словам Санчеса» против «Санчес заявил» считалось подменой
   человека. Сообщение выглядело как «изменено: X → X», где обе стороны одинаковы.

3. **Соцсеть вместо человека.** В новости «разместила на своей странице в соцсети X»
   разбор взял площадку за говорящего. Модель указывала настоящего автора и получала за это
   блокировку: наша разметка была хуже её результата. Плюс морфология считает фамилию
   «Аюсо» прилагательным и лемматизирует в «аюсый» — сравнение идёт по двум формам сразу.

4. **Рекламные хвосты изданий.** «Оставайтесь на связи с РБК в „Максе“» давало два
   «пропавших факта» в каждом пересказе, который этот хвост справедливо выбрасывал.
   На сервере такие хвосты были у 41 материала из 168 — публиковаться не могло вообще
   ничего. Проявилось только там: на ноутбуке в выборку попало меньше таких заметок.

5. **Единый порог непохожести.** Нейтральный пересказ нейтральной новости честно получал
   `COPY`. Порог стал свойством режима.

Отдельно: **код ответа 200 и число элементов в разметке не доказывают, что страница
выглядит как задумана.** Демо несколько часов отдавалось вообще без стилей — в nginx
`proxy_pass` со слэшем срезал префикс, а приложение ждало его в пути; страницы при этом
открывались, статика возвращала 404. Нашлось, только когда я посмотрел глазами.

## Как это развёрнуто

Конвейер живёт на машине автора, сервер только показывает готовую базу.

Из этого следует главное: **токен доступа к модели на публичной машине не нужен вообще**.
Публичный веб умеет ровно одно — читать SQLite. Сервис работает под отдельным системным
пользователем с `ProtectHome`, `ProtectSystem=strict`, белым списком каталогов на запись,
пустым набором привилегий и лимитом памяти; nginx ограничивает частоту запросов.

Публикация: `make publish` — снимок через `sqlite3 .backup` (не копированием: база в режиме
WAL), checkpoint, сжатие, атомарная подмена файла на сервере.

**Чем платим:** лента обновляется, когда автор запускает конвейер. На главной есть строка
«лента обновлена N назад», чтобы это было видно.

## Безопасность

Публичное демо с текстом, пришедшим из интернета, — это недоверенный ввод.

- Весь HTML с подсветкой фактов собирается **одной функцией** `app/highlight.py:render_spans`,
  которая экранирует каждый фрагмент. В шаблонах нет ни одного `|safe`.
  Тест проверяет, что строка `<img src=x onerror=alert(1)></mark><script>alert(2)</script>`
  не порождает ни одного живого тега, кроме наших.
- Ни одного внешнего адреса: шрифты (440 КБ) лежат локально, Swagger по умолчанию тянущийся
  с cdn.jsdelivr.net отключён. Проверяется тестом `test_tz_no_external_cdn_anywhere`.
- Промпт-инъекции: чужой текст изолирован блоком со случайной меткой.
- Живая перегенерация по умолчанию выключена (`ALLOW_LIVE_REGENERATE`): за ней стоит
  личная подписка автора, раздавать её посетителям нельзя.

## Право и этика

- Берутся только короткие новостные заметки — сообщения о фактах, которые не являются
  объектом авторского права (ст. 1259 п. 6 подп. 4 ГК РФ).
- Публикуется пересказ с плашкой «текст изменён нейросетью» и ссылкой на оригинал.
  Переписывание — это переработка (ст. 1270 п. 2 подп. 9), поэтому оригинал всегда рядом
  и всегда со ссылкой.
- Полные чужие тексты в репозиторий не кладутся.
- Чужие фотографии не показываются и не перезаливаются: вместо них цвет издания из хеша домена.
- `robots.txt` демо закрыт от индексации.
- Посетители не считаются: ни счётчиков, ни куки, ни логов свободного ввода.

## English abstract

Real Russian news, readable in four emotional registers, with a hard guarantee that facts
survive the rewrite. Numbers, dates, money, people, organisations, locations and quotations
are extracted from the source with character offsets, then matched against the rewritten
text through a ladder of comparisons (exact → numeric → spelled-out numerals → lemmas →
alias dictionary → fuzzy). A reverse pass catches anything invented. Publication is gated
by a rule, not a threshold: zero hard violations, zero hallucinations, no meaning flips,
sane length and language, and a minimum stylistic distance from the original — without that
last gate the model simply returns the source verbatim and scores a perfect 100%.
Every published text is linked to a specific model call at the schema level, so
hand-written variants are impossible by construction. Articles about people dying disable
the cheerful and ironic registers and say why. Stack: Python 3.12, FastAPI, SQLite,
natasha + pymorphy3 for Russian morphology. No external CDNs, no analytics, no cookies.
